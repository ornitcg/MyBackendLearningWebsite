# Backend מאפס ל-Scale

אתר קורס אישי ללימוד Backend ב-Node.js ו-TypeScript, מהבסיס ועד Scale ו-System Design.

- **13 מודולים ו-58 שיעורים.** בכל שיעור יש הסבר, השוואה ל-Python, קוד, תרגיל והערות.
- **פרויקט מתגלגל:** TaskFlow, REST API לניהול משימות בצוותים, שגדל משלב לשלב.
- **בכל מודול:** שלב בפרויקט, בוחן ושאלות ראיון.
- **מעקב התקדמות:** שיעורים, פרויקט, בחנים וימי למידה.

**הגרסה החיה:** https://claude.ai/artifact/K77Dgt48DpY3BECpt4DVCp

## מבנה

```
course-site/
├── index.html   # הממשק: ניווט, תצוגות, שמירת התקדמות, "שאלי את המורה"
└── course.js    # תוכן הקורס: מודולים, שיעורים, בחנים ושאלות ראיון
```

כדי להוסיף או לשנות תוכן, עורכים את `course-site/course.js`.

## הרצה מקומית

```bash
cd course-site
npx serve .
```

כשהאתר רץ מקומית, ההתקדמות נשמרת רק בדפדפן, ותיבת "שאלי את המורה" לא פעילה. שתי היכולות האלה עובדות רק בגרסה החיה ב-claude.ai.
